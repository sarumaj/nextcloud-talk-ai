# Security

## Supported versions

Only the latest release gets security fixes.

## Reporting a vulnerability

Please do not open a public issue. Report it privately, either by e-mail to the author address
in `appinfo/info.xml`, or through GitHub's private vulnerability reporting on the mirror
(*Security*, *Report a vulnerability*). Describe what is affected, how to reproduce it and what
an attacker gains.

You get a reply within a week. The fix comes in a new release, and the changelog names the
problem once the release is out.
